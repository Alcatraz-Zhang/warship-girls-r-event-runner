# 离线评测说明

## 目的与范围

本项目使用 [evals/evals.json](../evals/evals.json) 中的四个离线场景，检查回答是否覆盖安全执行工作流的关键行为。每个场景包含 6 条断言，共 24 条。评测只要求模型说明将如何判断和操作，不连接真实 MuMu 模拟器，不调用真实 ADB，也不对游戏账号发送任何输入。

## 场景

1. **端口与画面不一致：** 电脑和 MuMu 重启后历史 ADB 端口失效，用户肉眼画面又与旧截图冲突；检查动态目标发现、前台指纹、新截图和拒绝旧证据。
2. **带路、搜索与筛选：** 把攻略条件转换为舰队和入口约束；检查精确中文名搜索、舰种或国籍筛选、装备筛选，以及出击后等待自动带路而不手点路线节点。
3. **中断恢复：** 在旧记录可能是结算页、实时页面可能已回首页的情况下恢复；检查按新截图分支、核对持久战果后再决定是否重打、单证据单输入和大破或爆仓阻塞。
4. **复制人技能核验：** 面对同名、同改造、同等级但技能和状态不同的候选；检查收藏只作为定位线索、精确技能及等级优先，以及修理和检查点记录。

| 配置 | 通过断言 | 总断言 |

上表记录的是 2026-08-16 发布前使用旧标签版本评测场景完成的一次历史离线运行。此后场景采用了中性化标签，并补充了中文等价性说明，但没有按当前文本重新运行；因此，24/24 与 13/24 不是当前 [evals/evals.json](../evals/evals.json) 逐字版本的新结果。

每个配置只运行了一次。因此，24/24 与 13/24 只能说明这组固定场景下的方向性差异，不能估计波动、置信区间或对其他模型、版本、活动和真实运行环境的泛化表现，也不应被解读为安全保证。

## 不可比较的运行指标

现有记录中的时间、工具调用和 Token 聚合值为零，或相应字段在两种配置间缺失、命名和统计口径不一致。这些指标不能用于比较速度、成本或工具效率；本页只报告逐条断言的通过数。

## 数据与隐私

仓库只保留可审查的场景定义和这份汇总，不上传原始会话评测目录。原始会话可能包含模型输出、工具轨迹、本地路径或临时证据，即使没有连接模拟器也不适合纳入公开仓库。需要复核时，应从 [evals/evals.json](../evals/evals.json) 重新开展完全离线的评测，并在分享前单独进行去敏审查。
